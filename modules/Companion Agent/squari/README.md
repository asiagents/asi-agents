# Companion (Squari)

**Product:** ASI Agents  
**Module:** Companion Agent skins under `modules/Companion Agent/<skin>`  
**Canvas:** 1080×1920 (9:16)

## Out of the box

| Context | Companion |
|---------|-----------|
| Local (`127.0.0.1` / `localhost` / Vite DEV) | **ON** when unset — no setup |
| Production / remote host | **OFF** until Settings → Modules → Show Squari |

Assets serve at `/companion/<skin>/…`. Core chat works with Companion off.

## Skins

`squari`, `drakko` (default picker), `mochi`, `paperclip-x`, `capsule`, `nekowire`, `pixel-knight`
